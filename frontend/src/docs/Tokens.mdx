# Design System Tokens

Our design system is built on a "Quiet Luxury" minimalist beige theme.

## Color Palette

The following colors define our brand identity:

- **Background**: `#F2F2F2` (Neutral) - The primary background color.
- **Card / Muted**: `#EAE4D5` (Beige) - Secondary backgrounds and muted elements.
- **Accent**: `#B6B09F` (Sand) - Subtle highlights and interactive elements.
- **Foreground**: `#000000` (Black) - Text and high-contrast elements.
- **Primary**: `#000000` (Default) - Action colors.

## Typography

**Font Family:** Inter, sans-serif

**Weights:** 400 (Regular), 500 (Medium), 600 (Semi-bold), 700 (Bold)

Our typography system uses high-contrast black text for maximum readability against the beige background.
