## 🎨 Color Reference

### Component Colors
| Component | Color | Hex |
|-----------|-------|-----|
| Stats - Startups | Blue | #3B82F6 |
| Stats - Jobs | Green | #10B981 |
| Stats - Funding | Purple | #8B5CF6 |
| Stats - Watchlist | Orange | #F59E0B |
| Activity Type Badge | Varies | See below |
| Status Badge - Active | Green | #10B981 |
| Status Badge - Closed | Red | #EF4444 |
| Status Badge - Expired | Gray | #6B7280 |

### Activity Type Colors
| Type | Icon | Color |
|------|------|-------|
| startup_followed | 🚀 | Blue (#3B82F6) |
| job_saved | 💼 | Green (#10B981) |
| article_read | 📰 | Purple (#8B5CF6) |
| funding_update | 💰 | Orange (#F59E0B) |

### Background Colors
- Main background: Slate 50 (#F8FAFC)
- Card background: White (#FFFFFF)
- Hover state: Slate 50 (#F8FAFC)
- Section divider: Slate 200 (#E2E8F0)

## 📏 Spacing & Sizing

### Container
- Max width: 1280px (lg)
- Horizontal padding: 16px mobile, 24px tablet, 32px desktop
- Vertical padding: 32px

### Cards
- Border radius: 8px (rounded-lg)
- Padding: 24px
- Shadow: Card shadow (shadow)
- Border: 1px solid Slate 200

### Grid Gaps
- Mobile: 16px
- Tablet: 24px
- Desktop: 24px

### Typography
| Element | Font | Size | Weight |
|---------|------|------|--------|
| Page Title | Inter | 36px | 700 |
| Section Title | Inter | 20px | 700 |
| Card Title | Inter | 16px | 700 |
| Body Text | Inter | 14px | 400 |
| Label Text | Inter | 12px | 500 |

---

## 🎬 Animations

### Loading States
- Skeleton loader: `animate-pulse`
- Duration: 2 seconds
- Loop: infinite

### Hover Effects
- Card hover: `scale-105` with smooth transition
- Link hover: `opacity-80` or `bg-color-50`
- Button hover: `bg-color-700`

### Transitions
- Default duration: 200ms (ease-in-out)
- Hover effects: 150ms

## ♿ Accessibility

### Color Contrast
- Normal text: 4.5:1 (WCAG AA)
- Large text: 3:1 (WCAG AA)
- All colors have sufficient contrast

### Focus States
- All interactive elements have visible focus outline
- Focus color: Blue (#3B82F6)
- Outline width: 2px

### Keyboard Navigation
- Tab order: left to right, top to bottom
- All buttons and links keyboard accessible
- No keyboard traps

### Screen Readers
- All images have alt text
- Semantic HTML elements
- ARIA labels where needed
